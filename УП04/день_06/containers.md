# Контейнеры
**Запуск hello-world:**
- Команда: `sudo docker run hello-world`
- Результат: Выведено сообщение "Hello from Docker!".

**Запуск nginx:**
- Команда: `sudo docker run -d --name up04-web -p 127.0.0.1:8080:80 nginx:alpine`
- Проверка: `curl -I http://127.0.0.1:8080` вернула HTTP/1.1 200 OK.

**Ответы на вопросы:**
1. **Чем образ отличается от контейнера?** Образ — это неизменяемый шаблон (снимок файловой системы). Контейнер — это запущенный экземпляр образа, который можно изменять.
2. **Почему hello-world завершился, а nginx продолжает работать?** hello-world — это одноразовый скрипт, который выводит текст и завершает процесс. nginx — это демон (сервер), который работает в бесконечном цикле.
3. **Что означает -d?** Запуск контейнера в фоновом (detached) режиме.
4. **Что означает --name up04-web?** Присваивает контейнеру указанное имя для удобного управления.
5. **Зачем нужен порт 8080:80?** Пробрасывает порт 8080 хост-системы на порт 80 внутри контейнера.
6. **Почему указан адрес 127.0.0.1?** Чтобы сервис был доступен только локально (с самой машины), исключая внешний доступ.
7. **Как увидеть логи контейнера?** Командой `sudo docker logs up04-web`.
8. **Чем stop отличается от rm?** stop останавливает контейнер, сохраняя его. rm удаляет контейнер безвозвратно.
