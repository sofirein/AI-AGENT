# Заключение
В ходе работы я успешно установила Docker Engine в Ubuntu Server 24.04. Освоила базовые команды: запуск контейнеров, просмотр образов, логи, остановка и удаление.

Docker поможет при развертывании ИИ-агента, так как он позволяет упаковать все зависимости (Python, библиотеки) в один контейнер. Это избавит от проблемы "на моем компьютере все работает, а на сервере нет". Контейнер с агентом можно будет легко перенести на любой сервер.
