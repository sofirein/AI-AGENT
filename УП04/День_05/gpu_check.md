# Проверка GPU
Команда lspci и результат: `lspci | grep -Ei "vga|3d|display"` -> `00:02.0 VGA compatible controller: VMware SVGA II Adapter` (виртуальный адаптер).
Команда nvidia-smi и результат: `bash: nvidia-smi: command not found`
Доступен ли вычислительный GPU: Нет.
Требуется ли GPU моему агенту: Нет.
Обоснование: Агент использует облачный API GigaChat для генерации ответов, а для поиска по чанкам используется библиотека scikit-learn (TF-IDF), которая работает на центральном процессоре (CPU). Тяжелые локальные нейросети не запускаются, поэтому GPU не требуется.
