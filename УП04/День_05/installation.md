# Установка инструментов
Команды установки Git: `sudo apt update` и `sudo apt install -y git`
Команды установки Python и venv: `sudo apt install -y python3 python3-pip python3-venv`
Команда установки зависимостей: `python -m pip install -r requirements.txt`
Результат pip check: No broken requirements found (все пакеты совместимы).
Ошибки и их причины: Ошибок в процессе установки не возникло.
Что удалось исправить: Создано чистое виртуальное окружение .venv, в него установлены только необходимые библиотеки.
